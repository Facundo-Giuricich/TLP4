## 🛠️ Tecnologías

- **TypeScript** como lenguaje principal
- **Node.js** y **Express** para los servidores
- **Vitest** y **Supertest** para las pruebas automatizadas

## 🚀 Cómo ejecutar un proyecto

Cada carpeta es independiente. Para correr cualquiera de ellas:

```bash
cd <carpeta-del-proyecto>
npm install
npm run <script>
```

Los scripts disponibles están definidos en el `package.json` de cada proyecto.
